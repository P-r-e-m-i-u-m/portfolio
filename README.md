# Syed Abdul Aman | Portfolio

A personal portfolio for my work in applied AI, Python engineering, developer tooling, and open source.

**Live site:** https://p-r-e-m-i-u-m.github.io/portfolio/

## What you'll find

- Selected projects linked directly to their source repositories
- A concise overview of my current technical focus
- How I approach building and maintaining software
- Open-source work and ways to get in touch

## Built with

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Lucide icons
- Custom responsive CSS
- Framer Motion dependencies retained for future focused interactions

## Run locally

Requirements: Node.js 20.19+ or 22.12+.

```bash
git clone https://github.com/P-r-e-m-i-u-m/portfolio.git
cd portfolio
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Production build

```bash
npm run build
npm run preview
```

The project uses Vite's single-file plugin and is configured for the GitHub Pages `/portfolio/` base path.
